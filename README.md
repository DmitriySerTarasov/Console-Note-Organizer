# Console-Note-Organizer
Консольное приложение для управления заметками на Java + создание отдельного файла txt.


## 🚀 Возможности

- ➕ Добавление заметок с автоматической датой
- 📋 Просмотр всех заметок с нумерацией
- ❌ Удаление заметок по номеру
- 💾 Автоматическое сохранение в файл при выходе
- 📂 Загрузка заметок из файла при запуске
- ⚠️ Обработка ошибок (пустой текст, неверный номер)

---

## 🛠️ Технологии

- Java 17+
- `ArrayList` — хранение данных в памяти
- `FileWriter` / `BufferedReader` — работа с файлами
- `LocalDate` — автоматическая дата
- `Scanner` — ввод пользователя
